# ForDev Studio v2.0

منصة ويب متكاملة للمطورين تجمع بين تحويل صيغ الأكواد البرمجية، ونقل واجهات الويب إلى أطر التطبيقات، وتجهيز تغليف مشاريع بايثون والويب للهواتف، مع معاينة مباشرة وتلوين للصياغة وحفظ تلقائي للبيانات.

## الأدوات المتوفرة
1. **تحويل صيغ الأكواد:** تحويل الدوال والمنطق بين Python و JavaScript و JSON.
2. **الويب إلى تطبيقات:** تحويل عناصر HTML إلى واجهات في **Python Kivy** و **Python Tkinter** و **Flutter** و **React Native**.
3. **تغليف كود بايثون لتطبيق هاتف:** توليد إعدادات `buildozer.spec` أو `pyproject.toml` وأوامر البناء لتحويل سكربتات Python إلى تطبيق هاتف.
4. **تغليف كود الموقع:** تجهيز ملفات `manifest.json` (PWA) أو كود `WebView` لتغليف مواقع الويب.
5. **تنسيق وتجميل الأكواد:** ترتيب وتنسيق الأكواد بوضوح وسرعة.

## المزايا
* نبذة تعريفية واضحة + بوكسات أدوات منظمة بأيقونات SVG.
* وضع ليلي ونهاري + دعم اللغة العربية والإنجليزية.
* معاينة مباشرة لأكواد الويب + تلوين الكود في المخرجات.
* حفظ تلقائي للبيانات عند تحديث الصفحة.
